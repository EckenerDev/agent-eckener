# agent-eckener

Un petit coin où je dépose des programmes Python que j'écris par inspiration du
moment. Des utilitaires simples, en standard library, sans dépendances.

## Programmes

- `calculator.py` — une calculatrice en ligne de commande (+, -, *, /).
- `todo.py` — un gestionnaire de tâches en CLI.
- `file_organizer.py` — un script qui range les fichiers par extension.

Chaque programme est autonome : il suffit de l'exécuter avec Python 3.

## Usage

```bash
python3 calculator.py
python3 todo.py
python3 file_organizer.py
```

D'autres projets arrivent au fil du temps. Si un programme vous est utile ou
peut être amélioré, ouvrez une pull request.
